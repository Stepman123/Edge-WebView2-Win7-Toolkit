# Microsoft Edge & WebView2 Deployer & Toolkit для Windows 7 (x64)

> [English](README.md) | [Русский]

Интерактивный инструмент автоматизации для системного развёртывания, регистрации среды WebView2 и полного удаления браузера **Microsoft Edge** (как официальной финальной версии 109, так и современных сборок **110–153+**) на **Windows 7 SP1 x64**.

## 📌 В чём главная проблема и зачем нужен этот скрипт?

При попытке использовать современные версии Edge или WebView2 на Windows 7 пользователи сталкиваются с несколькими критическими барьерами:

1. **Невозможность прямого запуска установщика:**  
   Автономные пакеты Microsoft (`microsoftedgestandaloneinstallerx64_*.exe`) при прямом запуске на Windows 7 выдают ошибку неподдерживаемой ОС даже при активных слоях совместимости.
2. **Установка только в профиль пользователя (`AppData`):**  
   Даже если удаётся запустить распакованный установщик вручную, по умолчанию он часто встаёт как локальное приложение текущего пользователя (`Users\<Имя>\AppData\Local\...`). Скрипт принудительно запускает движок с ключом `--system-level`, устанавливая браузер общесистемно в `C:\Program Files (x86)\Microsoft\Edge`.
3. **Падение или зависание `setup.exe` на 100%:**  
   На завершающем этапе оригинальный установщик пытается зарегистрировать службы телеметрии и задачи Windows 10, которых в Windows 7 нет, из-за чего процесс установки падает или зависает. Скрипт отслеживает это по тайм-ауту и корректно освобождает систему.
4. **Сломанная регистрация WebView2 Runtime:**  
   Сторонние программы, требующие WebView2, не видят установленный Edge. Скрипт нормализует структуру папок `EdgeCore`, создаёт символические связи (junction) и внедряет полные ветки реестра для официальной регистрации среды.
5. **Невозможность штатного удаления:**  
   Edge, установленный с ключом `--system-level` в связке с расширенным API, невозможно корректно удалить через стандартную панель «Программы и компоненты». В скрипт встроен механизм очистки системы.

## 🚀 Основные возможности

* **Двухэтапная распаковка (7-Zip):** Извлечение чистого движка `setup.exe` и архива `MSEDGE.PACKED.7Z` напрямую из официальных офлайн-инсталляторов Microsoft Update Catalog без запуска их внешних блокирующих оболочек.
* **Поддержка любых режимов запуска:**
  * **Native Mode:** Для официальной финальной версии **109.x** (чистая Windows 7 без хуков).
  * **VxKex Mode:** Настройка хуков Application Verifier для версий 110–153+.
  * **Second System Mode:** Настройка инъекции `ntdlx.dll` с профилем `DefaultConfig` (Win10 22H2).
  * **Защита от взаимных блокировок (Deadlock Prevention):** Автоматическое отключение конкурирующих хуков перед запуском `setup.exe`.
* **Сторожевой таймер зависаний (Hang Watchdog):** Интерактивный диалог при превышении лимита времени распаковки (завершение процесса, ожидание или откат).
* **Глубокая интеграция WebView2:** Создание псевдонима `msedgewebview2.exe`, настройка каталога `EdgeCore` и импорт `.REG`-файла с подавлением плашек «Неподдерживаемая ОС».
* **Полное чистое удаление (Deep Clean Uninstall):**
  * Принудительное завершение всех связанных процессов.
  * Удаление системных служб (`edgeupdate`, `MicrosoftEdgeElevationService`) и задач планировщика.
  * Очистка системных каталогов `Program Files (x86)`, `ProgramData` и веток реестра `HKLM`.
  * Выборочное удаление пользовательских данных (история, пароли, куки, `HKCU`) по запросу.
* **Монитор и завершение зависших процессов:** Быстрое закрытие фоновых процессов браузера в один клик.

## 🛠 Системные требования

* **ОС:** Windows 7 SP1 (x64) с правами администратора.
* **Шрифт консоли CMD:** **Consolas** или **Lucida Console** (в свойствах окна `cmd.exe`).
* **Архиватор:** Установленный **7-Zip** (`7z.exe` / `7za.exe`) или положенный рядом со скриптом.
* **Для сборок 110+:** Установленный слой совместимости **VxKex** или **Second System (SS)**.
* **Исходный пакет:** Официальный автономный инсталлятор Microsoft Edge (x64), помещённый рядом со скриптом или в подпапку.

## 📖 Инструкция по использованию

1. Скачайте официальный автономный установщик Edge x64 (например, с Microsoft Update Catalog) и положите его в папку со скриптом.
2. Запустите `Edge_Win7_Toolkit_RU.bat` от имени администратора.
3. В главном меню выберите пункт `[1]` для установки:
   * Скрипт найдёт пакет, распакует полезную нагрузку во временную папку.
   * Предложит выбрать режим работы (Нативный 109, VxKex или Second System).
   * Запустит системную установку в `C:\Program Files (x86)`.
4. После окончания установки выберите пункт `[]` для исправления и регистрации среды WebView2.
